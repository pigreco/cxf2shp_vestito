Cos'è il plugin

CXF to Shapefile Vestito converte i file CXF (formato vettoriale del Catasto Italiano, distribuiti dall'Agenzia delle Entrate) in ESRI Shapefile o GeoPackage, caricandoli in QGIS con stili QML preconfigurati (colori, tratteggi, simboli catastali).

Come si usa

  1. Cartella sorgente — seleziona la cartella che contiene i file .cxf (anche più file per fogli diversi dello stesso comune).
  2. Formato output — scegli ESRI Shapefile (un file per layer) oppure GeoPackage (tutti i layer in un unico file catasto.gpkg).
  3. Cartella output — lascia vuoto per usare la sottocartella automatica (shape/ o catasto/ dentro la cartella CXF), oppure scegli una cartella personalizzata.
  4. Spunta Carica i layer nel progetto QGIS per vederli subito in mappa.
  5. Clicca ▶ Avvia Conversione.

CXF moderni vs storici (Cassini-Soldner)

I file CXF esistono in due varianti di sistema di riferimento:

TipoCoordinate X tipicheCRS
CXF moderni1.100.000 – 2.900.000Monte Mario (EPSG:3003/3004) — autodetect
CXF storici± poche migliaia di metriCassini-Soldner locale

CXF moderni (Roma 40): il plugin rileva automaticamente la zona Gauss-Boaga leggendo la prima coordinata X del file:

  • X tra 1.100.000 e 1.900.000 → EPSG:3003 (Monte Mario / Italy zone 1, nord-ovest Italia)
  • X tra 2.100.000 e 2.900.000 → EPSG:3004 (Monte Mario / Italy zone 2, centro-sud Italia)
Il CRS rilevato è riportato nel log (ℹ Autodetect CRS) ed eventualmente sovrascrive la selezione manuale nella dialog.

CXF storici (Cassini-Soldner): se le coordinate sono piccole (catasto storico), espandi la sezione Cassini-Soldner e attiva la spunta: il plugin leggerà automaticamente l'origine del comune dal file Italia_CS_PRJ_srtext.csv incluso nel plugin e trasformerà le coordinate nel CRS target scelto.

Note

  • I file CXF si ottengono dal portale Sister dell'Agenzia delle Entrate o dagli sportelli catastali comunali.
  • Gli stili QML sono salvati nella stessa cartella degli shapefile per il ricaricamento automatico da QGIS.
  • In caso di errore controlla il Log di esecuzione: riporta il file, il foglio e l'eventuale codice catastale non trovato nel CSV.
